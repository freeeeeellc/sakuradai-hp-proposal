## 2. 最大の論点 — 「桜台お助けマン」と重複している

調査で判明した**最重要事項**。桜台自治会には既に **「桜台お助けマン（お助けマン互助会）」** が存在し、**現役で稼働**しています（`/chiiki_katudou/otasukeman.htm`・**2026-07-30更新**）。

### お助けマンの実態
- 65歳以上・身体が不自由な方の暮らしを手伝う**会員制の互助組織**
- サービス: **電気器具点検・修理／屋外作業（庭木の伐採・刈り込み・草取り）／水回り（水漏れ・排水）／屋内作業／外出援助／家事手伝い／ヘアカット**
- 料金: **30分400円**＋材料・ガソリン代実費
- 会費: 利用会員 入会金1,000円／協力会員 免除／賛助会員 年1,000円〜（団体5,000円〜）
- 会員数: **120名**（協力23・利用88・賛助9）※平成31年3月末
- 申込先: **桜台自治会館 0436-66-1341**（＝自治会の代表電話）
- 千葉県社会福祉協議会の広報誌『福祉ちば』に掲載実績あり

### 重複している領域
**庭木の手入れ・水回り・電気器具** はサービス内容が正面から重なります。
しかも料金は **30分400円 vs 年会費12,000円**。何も整理しないまま自治会に持ち込むと、

> 「お助けマンがあるのに、なぜ？」
> 「自治会の互助会から客を取るのか」

で確実に止まります。**ここを先に片付けないと、他がどれだけ良くても通りません。**

### 整理の答え — 競合ではなく「受け皿」

| | 桜台お助けマン | さくらサービスセンター |
|---|---|---|
| 主体 | 住民同士の互助（協力会員＝ボランティア） | **有資格の専門業者**（企業会員） |
| 領域 | 資格も保険も要らない**軽作業** | **工事**：屋根・外壁塗装、給湯器交換、防犯カメラ設置、耐震補強、感震ブレーカー |
| 金額 | 30分400円の小口 | 数十万円規模＝**詐欺の温床になる価格帯** |
| 保険 | 協力会員の補償はQ&Aで個別対応 | **損害賠償保険加入が入会要件** |
| 目的 | 日常の困りごと | **悪質業者の防波堤**（無料点検） |

**お助けマンのFAQには「Q8. お助けマンで出来ない仕事がありますか？」という項目が既にあります。**
さくらサービスセンターは、そこに書かれた"できない仕事"の**正式な受け皿**として位置づけるのが唯一の正解です。

さらに補強材料が2つ:
- お助けマンは**協力会員23名に対し利用会員88名**。担い手が明確に不足しています（スライド2の「役員高齢化で成り手不足」と同じ構造）。**奪う話ではなく、支える話にできる**
- 料金表が「現在準備中」のまま。**さくら側の「価格表の明確化」はここを補完する**

> **アクション: 自治会役員会に上げる前に、お助けマン運営側と役割分担を合意しておく。** これが提案の成否を分けます。

## 4. 立場の整理（設計上の制約）

辻さんは**自治会役員であると同時に、住民に年会費12,000円のサービスを売る法人の代表理事**です。自治会公式サイトから有料サービスへ誘導すれば「自治会が特定業者に肩入れしている」と見られ、**事業と自治会の両方の信頼を同時に損ないます**。これは倫理の問題である以前に、事業が潰れるリスクです。

対処は難しくありません。**切り分ければいい。**

| | 方針 |
|---|---|
| 自治会サイト | **中立を保つ。** 悪質商法の注意喚起は「公共情報」として、消費生活センター・警察・国民生活センターと**並列**で扱う。特定業者名は出さない |
| さくらサービスセンター | **独立ドメインの独立HP**を持つ。会員募集・価格表・申込はすべてそちら |
| 連携 | **役員会／総会の正式決議**を経て「後援」として明示する。**決議を経た事実こそが信頼の源**になる |
| HP改善そのもの | **無償の地域貢献**として実施し、社外では実績として語る。ただし**自治会サイト上では宣伝しない** |

### 自治会サイト上で「やってはいけない」こと
- 決議前にさくらサービスセンターへのリンク・バナーを置く
- 「自治会推奨」「自治会公認」の表記
- 自治会サイトでの会員募集
- 回覧板PDFに案内を紛れ込ませる

### 逆に「やるべき」こと
- **自治会サイトを純粋に良くする。** これが最大かつ最速の信頼獲得手段
- **「悪質商法・訪問販売にご注意」ページの新設**（公共情報として）。クーリングオフの手順、消費生活センター 21-0844、警察 41-0110、国民生活センター。**辻さんの原体験そのもので、自治会にとって100%正当なコンテンツ**
- 空き家・高齢者見守りの現状を自治会と共有し、課題を可視化する

## 5. さくらサービスセンター側HPの要件（スライド5を踏まえ）

自治会サイトとは**設計を真逆にする**。読者が違うためです。

| 要素 | 設計方針 |
|---|---|
| **価格表** | スライドで「明確化」と明言されている通り、**必ず載せる。詐欺との差別化の核**がこれ。「無料点検→不要な工事は勧めない→価格は公開」の3点セット |
| **子世代向け導線** | 離れて暮らすご家族＝スマホ・PC世代。**親向けの大きな文字とは別の設計**でよい。「実家の屋根、大丈夫ですか」から入る |
| **企業会員一覧** | 顔写真・資格・**損害賠償保険加入の明示**。ここが「地元の知っている人」の証明になる |
| **代表挨拶** | 実家に来た詐欺同然の見積の話は**そのまま載せる**。最も強い説得材料 |
| **一般社団法人であることの説明** | 「非営利性・透明性」をスライドで謳っている以上、**なぜ株式会社ではないのかを言語化**する。ここを曖昧にすると訪問販売業者と区別がつかない |
| **LINE導線** | Lステップ登録。パソコン相談室での登録支援とセットで設計 |

## 6. 提案を通す順番

```
① 自治会サイト改善を「SKPの続き」として提案（無償・地域貢献）
   → 通れば信頼を獲得。ここでは事業の話を一切しない
        ↓
② お助けマン運営側と役割分担を合意（第2章）
   → 内部の反対を先に消す。ここが最大の関門
        ↓
③ 「悪質商法にご注意」ページを自治会と共同で整備
   → 事業テーマを自治会の公式テーマとして共有する
        ↓
④ 役員会へ「後援」を正式に諮る
        ↓
⑤ さくらサービスセンターHP公開・会員募集開始
```

**①〜③は事業の話をしないまま進む**のが要点です。順番を飛ばして⑤から入ると、①の信頼を使い切って終わります。

## 7. 確認したいこと

1. **お助けマン運営側との関係** — 辻さんは既に接点があるか。役割分担の話はできているか
2. **HP改善の提案先** — 役員会か、ホームページ作成委員会か。SKPの関係者は今も残っているか
3. **さくらサービスセンターHPの着手時期** — 自治会サイトと並行で作るか、①が通ってからか（**並行を推奨。ただし公開は④の後**）
4. **「後援」の想定レベル** — 名義後援だけか、回覧板での告知まで求めるか。後者なら総会決議が要る可能性が高い
